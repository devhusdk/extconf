# extconf

Typed configuration models for YAML, JSON, and TOML with recursive
inheritance through an `extends` key.

Status: not published. This repository exists ahead of its build; the Python
build, tests, lint, typecheck, and PyPI publishing land when `rules_dx`
reaches v1.0.0, using its Python preset end to end. Planning context lives in
the private Devhus workspace (`devhusdk/devhus`).
